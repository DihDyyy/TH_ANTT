Cấu hình build Docusaurus và GitLab Pages

Lê Đình Duy · MSSV 2387700102 · Lớp 23DATA1

Tệp: lab06-devsecops/.gitlab-ci.yml

stages:
  - build
  - deploy

build-job:
  stage: build
  image: node:22-bookworm-slim
  script:
    - npm install --no-audit --no-fund --fetch-retries=0 --fetch-timeout=15000
    - npm run build
  artifacts:
    paths:
      - build/
    expire_in: 1 week

pages:
  stage: deploy
  image: alpine:3.22
  dependencies:
    - build-job
  script:
    - mv build/ public/
  pages:
    publish: public
  artifacts:
    paths:
      - public/
  rules:
    - if: '$CI_COMMIT_BRANCH == $CI_DEFAULT_BRANCH'
YAML đã được phân tích cú pháp tại máy. Chưa chạy GitLab CI Lint. Khai báo pages.publish phục vụ GitLab hiện hành; chưa xác nhận triển khai thành công.
